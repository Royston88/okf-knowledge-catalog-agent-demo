# Subdirectories

* [datasets](datasets/index.md) - A simulated retail banking dataset modeling customers, accounts, transactions, and loans for testing the OKF projector mechanism.
* [references](references/index.md) - The references directory contains definitions for table relationships (joins) and core financial and operational metrics.
* [tables](tables/index.md) - Core banking tables detail Cymbal Bank customers, accounts, transactions, payments, loans, investors, and operational history.
